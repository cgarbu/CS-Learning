## Basic Computing

1. At the core of modern computing is the microprocessor, a self-contained unit etched with microscopic gates and channels that performs fundamental data processing.

2. The calculator model conceptualizes a computer as feeding an instruction stream and a data stream into the arithmetic logic unit to produce an output stream of results.

3. The file-clerk model defines computation as a continuous read-modify-write cycle where numbers are retrieved, altered, and written back to storage until a halt condition.

4. Modern computers differ fundamentally from earlier calculating machines by using stored-program architecture to retain reusable sequences of instructions alongside data.

5. A functional computer relies on three primary hardware structures: storage to hold values, an arithmetic logic unit to modify them, and buses to transmit information between components.

6. To prevent computational bottlenecks caused by slower storage, processors use a register file containing a small set of extremely fast storage cells located adjacent to the arithmetic  logic unit.

7. Arithmetic execution follows a three-step cycle of loading operands from source registers, calculating the result in the arithmetic logic unit, and saving that result into a destination register.

8. Main random access memory provides the expansive capacity needed for large datasets, communicating with processor registers across an external memory bus.

9. Programs consist of ordered sequences of instructions that coordinate both memory transfers and arithmetic operations across the processor.

10. The processor's instruction set fundamentally divides into arithmetic instructions carried out by the execution units and memory-access instructions that explicitly load or store data.

11. Operations can manipulate variables stored in registers or directly incorporate constant values called immediate values.

12. Because memory addresses are standard integers, they can be saved, moved, and computed within general-purpose registers and memory cells.

13. Register-relative addressing computes memory locations dynamically by adding an offset to a base address held in a register, decoupling programs from absolute locations.
